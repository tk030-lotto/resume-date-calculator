# 履歴書・学歴・年次自動計算機（ResumeDateCalc）

生年月日を選ぶだけで、現在の満年齢、和暦、日齢、干支・厄年・年祝い、そして履歴書作成に利用できる正確な学歴年月（入学・卒業）を自動計算するブラウザ完結型ツールです。  
外部サーバーとの通信は一切行わず、お使いのパソコンのブラウザ内だけで処理されます。

## こんなときに

- 履歴書や職務経歴書を書くときに、小学校・中学校・高校・大学の入学・卒業年月を正確に知りたいとき
- 早生まれ（1月1日〜4月1日生まれ）で、通常の年度計算とずれて分からなくなってしまうとき
- 浪人や留年、休学、短期大学・専門学校・高専・大学院などの進路に応じた学歴年月を調べたいとき
- 今日の満年齢や和暦（令和・平成・昭和）、生まれてからの日数（日齢）、今年の厄年や年祝い（還暦など）を確認したいとき
- 生年月日などの個人情報を外部サーバーに送信することなく、手元の端末内だけで計算したいとき

## 主な機能

- **早生まれ対応の学歴年月自動計算**: 年齢計算ニ関スル法律・民法143条・学校教育法に準拠し、4月1日生まれなどの境界ケースも正確に算出します。
- **多様な進路コース対応**: 4年制大学、6年制大学、短期大学、専門学校（2〜4年制）、高等専門学校（5年制）、大学院修士課程、高校卒まで幅広く対応します。
- **浪人・留年（休学）の年数指定**: 入学遅延と在籍延長を個別に設定できます。
- **履歴書実務に即したカスタマイズ**: 表示範囲（高校以降 / 中学卒業〜 / 全学歴）、年号表記形式（西暦（和暦）併記 / 西暦のみ / 和暦のみ）をワンクリックで切り替えられます。
- **学校名インライン入力と一括コピー**: 表上で学校名・学部学科名を入力でき、「履歴書用テキストを一括コピー」ボタンでWord・Excel・Webフォーム貼り付け用のタブ区切りテキストを即時取得できます。
- **サマリー情報**: 満年齢、今日の和暦、日齢（生後日数）、干支、生年和暦、厄年・年祝いの案内バナーを表示します。

## 使い方

### ブラウザで使う（かんたん）

1. [履歴書・学歴・年次自動計算機を開く](https://tk030-lotto.github.io/resume-date-calculator/) をクリックします（またはダウンロードした `index.html` をブラウザで開きます）。
2. 「生年月日・属性の設定」で、「生年」「誕生月」「誕生日」を選びます。
3. 必要なら、「性別（厄年計算用）」で「指定なし」「男性」「女性」のいずれかを選びます。
4. 「基本情報サマリー」に、満年齢、今日の和暦、日齢、干支が表示されます（該当する場合は厄年や年祝いの案内バナーも表示されます）。
5. 「履歴書・学歴カスタマイズ」で、「進路区分」を選びます。必要なら「浪人年数（進学遅延）」「留年・休学年数（在籍延長）」「表示範囲」「年号表記形式」を設定します。
6. 「履歴書用学歴タイムライン」の表に、入学・卒業年月の一覧が表示されます。必要なら、各行の「学校名・学部学科名（任意入力）」の欄に学校名を入力します。
7. 「履歴書用テキストを一括コピー」を押します。クリップボードにタブ区切りテキストがコピーされます。

### ダウンロードして使う（パソコンに保存する場合）

1. 本リポジトリのファイルを一括ダウンロードまたはクローンします。
2. Windows をお使いの場合は、フォルダ内の **`ツール起動.bat`** をダブルクリックすると、既定のブラウザで即座に起動します。
3. Mac や Linux の場合は、`index.html` をお好みのブラウザで直接開いてください。インターネット接続がなくても動作します。

## うまくいかないとき

- **2月29日や31日などが選べないとき**: 選択した「生年」および「誕生月」に実在する日付のみが「誕生日」に表示されます（うるう年以外の2月29日などは選べない仕様です）。
- **一括コピーが動かないとき**: お使いのブラウザでクリップボードへのアクセスが許可されているかご確認ください。

## 動作環境

- モダンWebブラウザ（Google Chrome, Microsoft Edge, Mozilla Firefox, Apple Safari）
- インターネット接続は不要です（オフライン環境でも動作します）。

## 制限・注意

- **計算基準**: 本ツールの学歴年月は、日本の学校教育法および関連法令に基づく標準的な修業年限（小学校6年、中学校3年、高校3年など）を前提としています。飛び級や早期卒業、秋入学・海外留学等の特殊な就学形態には対応していません。
- **データの保存**: 入力された生年月日や学校名は、ブラウザのメモリ内でのみ一時的に保持されます。CookieやLocalStorage等への保存は行われないため、ページを再読み込みすると初期状態に戻ります。

## 外部通信

- **外部通信は一切行いません**。
  入力された生年月日や属性情報、学校名が外部のサーバーに送信されることはありません。Content Security Policy（CSP）により、外部通信を技術的にも遮断しています。

## 免責事項

本ツールの計算結果は一般的な法令・慣例に基づく目安です。公的な履歴書や申請書類等の作成・提出にあたっては、必ずご自身で卒業証明書等をご確認の上ご利用ください。
